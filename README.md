## 课程修读与避坑指南（学长实战经验）

### 1. 课程定位与技术价值
- 本课程为自动化专业软件技术方向选修课，授课教师同样为虞旦老师，教学风格与要求与《[深度学习理论与应用实践（WG320940）](../深度学习理论与应用实践/)》一脉相承；
- 自动化专业的 C# 核心定位是**工控上位机软件开发**：配合下位机 PLC 或单片机，编写友好直观的桌面监控软件（GUI 交互界面、串口/以太网通信报文解析、实时曲线绘制与历史数据存盘）。

### 2. 考核机制与答辩演进
- 本课程为考察课，不设期末闭卷笔试；
- 成绩主要由**平时实验小作业**与**期末综合大作业报告**构成；
- **答辩形式演变与避坑**：
  - 结课阶段通常因时间紧张，无法逐一组织线下上台答辩，老师往往会要求提交包含运行演示的视频录像；
  - 考虑到演示录屏视频体积较大且包含出镜隐私，本归档仓库按规范剔除了冗余视频文件，完整保留了全部工程源码、数据库脚本与高质量大报告成果。
